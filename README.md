## 🎯 Про проєкт
Проєкт створений для допомоги українській Web3-спільноті у пошуку та верифікації перспективних крипто-проєктів на ранніх стадіях. Ми аналізуємо активності в мережах Ethereum, ZkSync, LayerZero, Starknet та інших.

### Ключові можливості:
- **Daily Monitoring:** Щоденне оновлення списку актуальних дропів.
- **Scam Protection:** Перевірка проєктів на надійність та наявність Tier-1 фондів.
- **Educational Guides:** Покрокові інструкції для проходження активностей.

## 📈 Технологічний стек
Проєкт використовує сучасні методи збору та аналізу даних з блокчейну для надання максимально актуальної інформації про знімки мережі (snapshots) та умови розподілу токенів.
